### 🏛️ About Me

Software Engineer and Cybersecurity Scholar specializing in **Applied Cryptography**, **Multi-Tenant System Architecture**, and **Autonomous AI Systems**. Currently completing an intensive four-year engineering curriculum at **Politeknik Siber dan Sandi Negara (National Cyber and Crypto Polytechnic - BSSN)** with focus on software resilience, cryptographic primitives, and secure distributed protocols.

- ⚙️ **Core Focus:** Building high-integrity digital systems where mathematical security, operational velocity, and intuitive product ergonomics converge.
- 🔐 **Cryptographic Engineering:** Designing and implementing on-chain zero-knowledge verification (curve25519 Dalek, Schnorr proof-of-liveness), Shamir Secret Sharing over Galois Fields $GF(2^8)$, and RFC 9180 HPKE architectures.
- 🚀 **Full-Stack & Cloud Architecture:** Architecting containerized cloud infrastructure, reactive TypeScript interfaces, and resilient edge APIs backed by relational and memory stores.
- 🤖 **Applied AI & Tooling:** Engineering autonomous tool-using agent pipelines, multi-persona simulations, and LLM-driven software verification loops.

**Open To:** High-impact engineering collaborations, vulnerability assessments, security architecture design, and Web3/Solana cryptographic protocol development.

<details open>
<summary><b>01. SIKRIT — Privacy-Preserving Dead Man's Switch Protocol</b></summary>
<br/>

> **Decentralized, zero-knowledge digital legacy and inheritance protocol deployed on Solana Devnet.**

| Attribute | Specification |
| :--- | :--- |
| **Core Stack** | Rust (Anchor 0.30.1), curve25519-dalek, TypeScript, LiteSVM, React, Vite, Tailwind CSS v4 |
| **On-Chain Scale** | 7 account structures, multi-guardian consensus bitmap, optimized for ~41,000 Compute Units |
| **Performance** | Sub-second proof validation using native Solana curve25519 arithmetic syscalls |
| **Security** | Zero-Knowledge Schnorr proof-of-liveness; zero correlation between owner identity and public transactions |
| **Impact** | Colosseum Crypto World's Fair 2026 Finalist; solves private seed/credential inheritance without centralized custody |
| **Repository** | [github.com/Darkside0908/SIKRIT](https://github.com/Darkside0908/SIKRIT) |

SIKRIT enables crypto asset holders to configure cryptographic dead man's switch capsules without revealing secret shares, heir identities, or heartbeat activity on public ledgers. Built with a 72-case automated test suite (Rust unit tests and LiteSVM TypeScript integration) and verified against front-running and replay attacks.
</details>
